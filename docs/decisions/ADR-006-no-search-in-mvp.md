# ADR-006: Mahsulot qidiruvi MVP scope'iga kirmaydi

- **Status:** Accepted for MVP
- **Decision date:** 2026-10-12

## Context

Dastlabki muhokamada mahsulot nomi bo‘yicha qidiruv g‘oyasi tilga olingan, ammo foydalanuvchi funksional scope'ni keyinroq categories → category products → product detail → favorites bilan yakunlagan.

## Decision

MVPda search endpoint/UI yo‘q. Mahsulot qidiruvi keyingi alohida feature bo‘lishi mumkin; talab tasdiqlanmaguncha implement qilinmaydi.

## Consequences

- MVP kichikroq va tezroq tekshiriladi.
- Katalog kattalashib, qidiruv aniq biznes ehtiyojiga aylansa, API contract, UI va qidiruv strategiyasi alohida qaror qilinadi.
